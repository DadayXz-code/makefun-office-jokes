One line about office life, under 200 characters, written to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. The joke turns the most passive-aggressive phrase in office email — "per my last email" — into an out-of-office reply, so even being away from the office sounds passive-aggressive. The program is deterministic and dependency-free: run it twice and the output is byte-identical.

## Run it

```sh
python3 main.py
```
